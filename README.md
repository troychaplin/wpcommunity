# wpcommunity.ca

A bilingual (English / French) directory of WordPress meetups and community across Canada.

Built with [React Router](https://reactrouter.com) 8 in framework mode on [Vite](https://vite.dev). Every page is prerendered to static HTML at build time, in both languages, so the site needs no server and can be hosted as plain files.

## Getting started

Requires Node 22.22 or newer and pnpm.

```bash
pnpm install
pnpm dev
```

Open [http://localhost:5173](http://localhost:5173). `/` redirects to `/en` or `/fr` from your browser's languages.

## Scripts

| Script | What it does |
| --- | --- |
| `pnpm dev` | Generates design tokens, then starts the dev server |
| `pnpm build` | Generates design tokens, then prerenders every page to `build/client` |
| `pnpm preview` | Serves `build/client` as static files, the way a host will |
| `pnpm typecheck` | Generates route types, then runs TypeScript |
| `pnpm lint` | Runs ESLint |
| `pnpm tokens` | Regenerates the design tokens from `c2b.config.json` |

## Where things live

| Path | Contents |
| --- | --- |
| `src/app/` | The app: `root.tsx` (HTML shell), `routes.ts` (route table) and the route modules in `routes/` |
| `src/components/` | Router-free UI components, documented in [`docs/components/`](./docs/components/README.md) |
| `src/features/` | App code that wires components to data: the directory search, the group form, the language switcher |
| `src/data/` | Typed mock data for groups, regions, updates and FAQ |
| `src/i18n/` | Locales, dictionaries and the `useI18n()` hook |
| `src/styles/` | Global styles, fonts and the tokens generated by [component2block](https://www.npmjs.com/package/@troychaplin/component2block) |

Adding a page means adding it to `src/app/routes.ts` and, so it ships as HTML, to the `prerender` list in `react-router.config.ts`.

## Deploying

`pnpm build` writes a complete static site to `build/client`. Every path has its own `index.html`, and `__spa-fallback.html` can serve any other path.
