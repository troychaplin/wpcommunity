# WP Community Canada components

The UI components behind [wpcommunity.ca](https://wpcommunity.ca), a bilingual directory of WordPress meetups across Canada. Each one has a full spec in [`docs/components/`](https://github.com/troychaplin/wpcommunity.ca/tree/main/docs/components) of the repository.

## Groups

The sidebar follows the component inventory:

- **Foundations**: buttons, headings, eyebrows, links, pills, avatars and icons.
- **Page Structure**: `Main`, `Article` and `Aside`. `Body` renders the page's `<body>`, so it has no story.
- **Layout**: `Container` with its five tones, `SectionHeader`, `GridGroup`, `Column` and `FlexGroup`.
- **Content**: cards, lists, the FAQ accordion, form controls and the Slack preview.
- **Sections**: the site header and footer, the homepage hero and Meetup Index, and the group page header and event band.

## Conventions

- Every visual value comes from a `--wpc--*` design token generated from `c2b.config.json`.
- Components take their user-facing strings as props with English defaults, so the site can pass French.
- Components never import a router. Links render a plain `<a>` here; the site swaps in React Router's link through `LinkProvider`.
- Interactive components are controlled. The stories that need state, such as **Content / FilterBar**, own it in a small wrapper.
