# Colors

Color tokens are defined in `c2b.config.json` and generate CSS custom properties prefixed with `--wpc--color-*`. Components read the **role** colours, so they adapt when a `Container` or `Card` sets a tone; the **palette** is what the roles point at.

## Usage

Use roles for anything that sits on a toned surface, and palette colours only where a value must stay fixed (buttons do this so they look the same in every section).

```css
.my-element {
    color: var(--wpc--color-text);
    border-color: var(--wpc--color-border);
}
```
