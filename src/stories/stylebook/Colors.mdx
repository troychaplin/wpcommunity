# Colors

Color tokens are defined in `c2b.config.json` and generate CSS custom properties prefixed with `--wpc--color-*`. The **palette** is four colour families on one lightness scale. **Roles** say what a colour is for and point at a palette step. Components read roles, or a [surface](?path=/docs/overview-stylebook-surfaces--docs), so they adapt when a section changes tone.

## Palette

Each family is named `{family}-{step}`, and a step means the same lightness in every family (measured in OKLCH): `200` is a light border colour whether it's stone or sage, and `900` is a deep text-weight colour in both greens. Gaps in the numbering are left free for later steps.

## Usage

Use roles for anything that sits on a toned surface, surfaces for anything with a background, and palette steps only where a value must stay fixed.

```css
.my-element {
    color: var(--wpc--color-text);
    border-color: var(--wpc--color-border);
}

.my-element:hover {
    border-color: var(--wpc--color-border-hover);
}
```
